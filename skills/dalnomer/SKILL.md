# Дальномер

Поговорки из сборника В. И. Даля «Пословицы русского народа», отмеренные к месту.

Поговорка украшает работу, но не заменяет её. Одна строка к месту, не больше.

## Откуда брать

Только из данных скилла через скрипт, никогда не из памяти и не собственного сочинения:

```bash
python scripts/pick.py day                # Месяцеслов на сегодня
python scripts/pick.py <момент>           # 3 кандидата для момента
python scripts/pick.py <момент> -n 5      # больше кандидатов, если первые не подошли
```

Путь `scripts/pick.py` считается от папки этого скилла.

## Когда давать

| Момент | Ключ | Когда |
|---|---|---|
| Начало сессии | `day` | первый ответ в сессии, в котором начинается работа |
| Старт задачи | `start` | взялись за новую крупную задачу |
| Планирование | `plan` | предлагаем план или выбираем подход |
| Риск | `risk` | перед необратимым: удаление, миграция, запись в рабочую базу, force-push |
| Найдена причина | `bug` | нашли корень ошибки |
| Долгая работа | `long` | задача затянулась, много однотипных шагов |
| Тупик | `stuck` | несколько попыток не дали результата, меняем подход |
| Проверка | `review` | ревью кода, сверка результата с ожиданием |
| Спешка | `hurry` | пользователь торопит или соблазн срезать угол |
| Ремесло | `craft` | работа с инструментом, изучаем новое API |
| Вопрос пользователю | `ask` | нужно уточнение или согласие |
| Чужой код | `legacy` | разбираем унаследованный или сторонний код |
| Неудача | `failure` | тесты упали, откат, потеря работы |
| Готово | `done` | задача завершена и проверена |

Частота: начало сессии плюс не чаще одной поговорки на 3-5 содержательных ответов. Если момент неважный, поговорку пропустить. Пользователь просит без поговорок - прекратить до конца сессии.

## Как выбирать

Скрипт даёт сырые строки сборника без ручного отбора. Из кандидатов взять одну, которая:

- понятна без словаря и подходит к ситуации по смыслу;
- не грубая, не про религию, власть, наказания, пьянство, внешность, народности, отношения полов;
- если в строке несколько вариантов через точку, взять одно предложение.

Ни один не подошёл - запросить ещё (`-n 5`). Снова нет - пропустить, а не сочинять.

Пояснения Даля в скобках (`т. е. …`, `или: …`) убирать, если без них ясно. Если слово устарело («зепь», «лутошка»), дать короткое пояснение в скобках после поговорки.

Для `day`: скрипт выводит записи дня, а если их нет - три поговорки к началу работы (`start`), плюс поговорки месяца. Уже выданные в прошлых сессиях строки скрипт пропускает, поэтому брать из того, что он дал, а не из памяти. Предпочесть запись дня: народное присловье или примету о погоде и работе, а не описание обряда или церковного праздника. Записи дня нет - взять поговорку к началу работы или поговорку месяца. Название дня можно упомянуть: «Семён-летопроводец».

## Как оформлять

Отдельной строкой в начале ответа (после обязательного обращения к пользователю, если оно есть), курсивом, с подписью «— Даль»:

> *Семь раз примерь, один раз отрежь.* — Даль

> *Холоден сентябрь, да сыт.* — Даль

Раздел сборника, Месяцеслов и дату по старому стилю в подписи не указывать. Без вступлений вроде «как говорится» и без разбора поговорки. Не больше одной поговорки в ответе.

## Где не использовать

Код, комментарии в коде, коммиты, PR, файлы и документы, которые пишутся для пользователя. Поговорка живёт только в репликах чата.
