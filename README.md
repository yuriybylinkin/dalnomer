# Дальномер

Скилл для [Claude Code](https://claude.com/claude-code) и ZCode: поговорки из сборника В. И. Даля
«Пословицы русского народа» в рабочей сессии. В начале работы Claude даёт поговорку дня
из Месяцеслова, а дальше, в ключевые моменты, одну поговорку к месту: перед рискованным
действием, когда нашлась причина бага, когда задача готова.

> *Холоден сентябрь, да сыт.* — Даль

> *Семь раз примерь, один раз отрежь.* — Даль

Поговорки берутся только из сборника, через скрипт. Claude не сочиняет их и не вспоминает
по памяти, а выбирает одну из нескольких случайных строк нужного раздела.

*English: a Claude Code skill that adds a fitting Russian proverb from Vladimir Dal's
collection at the start of a session and at key moments of work. Russian-speaking users only.*

## Установка

Нужен Python 3.9+ (без сторонних библиотек).

### Как плагин

В Claude Code:

```
/plugin marketplace add yuriybylinkin/dalnomer
/plugin install dalnomer@dalnomer
```

### Вручную

Скопировать папку `skills/dalnomer` в `~/.claude/skills/` (для всех проектов)
или в `.claude/skills/` нужного проекта:

```bash
git clone https://github.com/yuriybylinkin/dalnomer.git
cp -r dalnomer/skills/dalnomer ~/.claude/skills/
```

В ZCode скилл ставится так же, в `~/.zcode/skills/`:

```bash
cp -r dalnomer/skills/dalnomer ~/.zcode/skills/
```

### Чтобы поговорка дня приходила сама

Скилл срабатывает по описанию, но надёжнее прописать его в `~/.claude/CLAUDE.md`
(для ZCode — в `~/.zcode/AGENTS.md`):

```markdown
## Дальномер (поговорки Даля)

- В начале работы в каждой сессии вызывать скилл **dalnomer** (Дальномер) и дать поговорку дня
  из Месяцеслова. Дальше - в ключевые моменты по правилам скилла (не чаще одной на 3-5 ответов).
```

Можно и просто попросить: «дай поговорку», «поговорка дня», «что сказал бы Даль».
Фраза «без поговорок» выключает их до конца сессии.

## Как это устроено

```
skills/dalnomer/
  SKILL.md                правила: когда давать поговорку, как выбирать и оформлять
  scripts/pick.py         выбор случайных строк из данных
  data/mesyatseslov.json  Месяцеслов по дням старого стиля
  data/moments/*.txt      поговорки по моментам работы
tools/
  fetch.py                выгрузка сборника с Викитеки в raw/
  build.py                сборка data/ из raw/
```

Скрипт можно запускать и руками:

```bash
python skills/dalnomer/scripts/pick.py day          # Месяцеслов на сегодня
python skills/dalnomer/scripts/pick.py day 2026-10-14
python skills/dalnomer/scripts/pick.py risk -n 5    # 5 кандидатов к моменту «риск»
python skills/dalnomer/scripts/pick.py list         # список моментов
```

Моменты и разделы Даля, из которых они собраны:

| Момент | Когда | Разделы |
|---|---|---|
| `start` | взялись за новую задачу | Начало — Конец, Работа — Праздность, Путь — Дорога |
| `plan` | план, выбор подхода | Раздумье — Решимость, Забота — Опыт, Запас, Ум — Глупость |
| `risk` | перед необратимым действием | Осторожность, Оплошность — Расторопность, Нечаянность — Расплох |
| `bug` | нашли причину ошибки | Причина — Следствие, Повод — Причина, Сознание — Улика, Вина — Заслуга |
| `long` | задача затянулась | Терпение — Надежда, Судьба — Терпение — Надежда, Упорство |
| `stuck` | тупик, меняем подход | Поиск — Находка, Толк — Бестолочь, Тайна — Любопытство, Чудо — Диво — Мудреное |
| `review` | ревью, сверка результата | Правда — Кривда, Сущность — Наружность, Верное — Надежное, Прямота — Лукавство |
| `hurry` | спешка | Пора — Мера — Успех, Покой — Движение |
| `craft` | новый инструмент или API | Ремесло — Снаряд, Ремесло — Мастеровой, Ученье — Наука |
| `ask` | вопрос пользователю | Просьба — Согласие — Отказ, Язык — Речь, Помощь — Кстати |
| `legacy` | чужой код | Свое — Чужое, Наследство — Подарок |
| `failure` | тесты упали, откат | Горе — Утешение, Счастье — Удача |
| `done` | задача готова | Начало — Конец, Хорошо — Худо, Похвала — Похвальба |

Всего около 9 300 поговорок и 172 дня с записями Месяцеслова.

Даль вёл Месяцеслов по старому стилю, поэтому скрипт отнимает от даты 13 дней
(верно для 1900-2099 годов). Выданные строки запоминаются во временном файле
`dalnomer-recent.json` (последние 300) и не повторяются.

## Ограничения

- Строки не отобраны вручную. `build.py` отсекает длинные строки и часть неуместных
  по словарю, остальное Claude отсеивает при выборе по правилам из `SKILL.md`.
  Поэтому среди кандидатов попадаются тёмные или устаревшие поговорки, и иногда
  подходящей не находится - тогда поговорка пропускается.
- Не во все дни есть записи Месяцеслова. В такие дни скрипт выдаёт поговорки к началу
  работы и поговорки месяца.
- Разбивка по моментам грубая: раздел Даля подходит к ситуации в целом, а не каждая его строка.

## Пересборка данных

```bash
python tools/fetch.py   # скачать разделы в raw/ (около 180 запросов с паузой 3 с)
python tools/build.py   # собрать skills/dalnomer/data/
```

Состав моментов и фильтр задаются в начале `tools/build.py` (`MOMENTS`, `BAD`, `MAX_LEN`).
